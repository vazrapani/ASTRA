# Astra Tarot 모듈 구조

## 1. 인증 모듈 (auth)
- 사용자 인증 관련 기능
- 소셜 로그인 처리
- 게스트 모드 관리

## 2. 타로 모듈 (tarot)
- 타로 카드 데이터 관리
- 카드 리딩 로직
- 해석 생성 및 저장

## 3. 크레딧 모듈 (credits)
- 크레딧 시스템 관리
- 광고 보상 처리
- 결제 처리

## 4. 소셜 모듈 (social)
- 친구 관리
- 공유 기능
- 메시지 시스템

## 5. 관리자 모듈 (admin)
- 시스템 설정 관리
- 사용자 관리
- 통계 및 모니터링

## 6. UI 모듈 (ui)
- 공통 컴포넌트
- 애니메이션
- 테마 관리

각 모듈은 독립적으로 동작하며, 필요한 경우에만 다른 모듈과 통신합니다.
모듈 간 통신은 Redux를 통해 이루어지며, 각 모듈은 자체적인 상태 관리와 비즈니스 로직을 가집니다.
